# dbf-lakehouse-migration-lab
A hands-on legacy DBF → Bronze/Silver/Gold Delta lakehouse migration exercise.
This lab simulates a real legacy-to-cloud migration: dBase III files are ingested raw into a Bronze Delta layer, validated and quarantined into Silver (25 of 408 records rejected with reasons), and curated into Gold business tables. Built as part of my AI readiness program, July 2026.
